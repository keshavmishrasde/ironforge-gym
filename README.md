# 🏋️ IronForge Gym

Responsive gym website built with **React** and **Tailwind CSS**.

🚧 **Status: In progress**

🔗 **Live demo:** https://ironforgegym7.netlify.app/

## Done
- Navbar (responsive, hamburger on mobile)
- Hero section
- Stats section

## Coming soon
- Programs, Trainers, Pricing, Contact, Footer

## Tech
React (Vite) · Tailwind CSS · Lucide React

## Run locally
```bash
git clone https://github.com/keshavmishrasde/ironforge-gym.git
cd ironforge-gym
npm install
npm run dev
```
